## Краткая сводка ключевых правил

### Git
- **ЗАПРЕЩЕНО** выполнять git операции (commit, push, pull и т.д.) без явного разрешения пользователя
- Разрешено: `git diff`, `git status`, `git log` (только чтение)

### Сборка
- **ЗАПРЕЩЕНО** использовать прямые вызовы `cargo build` / `npx tauri build`
- Всё ТОЛЬКО через `build.bat`
- `build.bat` обязан инициализировать MSVC окружение (vcvarsall.bat)
- В `.bat` файлах только ASCII символы, CRLF переносы, комментарии `REM`

### Архитектура
- Модули по Doors Pattern — единая точка входа (lib.rs / index.ts)
- Файлы < 300-500 строк
- `unwrap()` вне тестов запрещён — использовать `?` или `map_err`
- Единый источник правды (SSOT)

### Код-стайл
- Функции < 50-80 строк
- Не глушить ошибки пустыми catch
- Логировать неочевидные пути кода

### Зависимости и Автономность
- **ЗАПРЕЩЕНО** требовать от пользователя ручную установку системных зависимостей (Visual Studio, Rust, Node.js и т.д.)
- Приложение **ОБЯЗАНО** работать из коробки после клонирования репозитория
- Допустимый вариант: автодокачивание автономных зависимостей из интернета (например, NSIS, sidecar бинарники)
- `build.bat` **ОБЯЗАН** сам подтягивать всё необходимое для сборки
- Если зависимость нельзя автодокачать — она должна быть прописана в `README.md` с инструкцией по установке
